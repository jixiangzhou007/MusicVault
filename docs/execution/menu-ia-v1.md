在 v1 基础上升级为专业版信息架构：突出来源管理、下载运营与工具属性，支撑后续功能扩展。

## 命名规则（v2）

1. 菜单用名词，按钮用动词。  
2. 一级导航优先 2~6 字，避免歧义词。  
3. 用户高频词优先于技术词（下载 > 传输）。  
4. 同一动作只保留一个词，避免同义词并存。  
5. 中英文文案必须同步更新，避免跨语言语义漂移。  
6. 设置分组遵循“配置对象优先”原则（在线源配置、下载策略）。

## 下轮候选（v2.1）

- 一级导航是否引入“工作区模式”（曲库优先 / 下载优先）切换。
- 下载中心增加“视图预设”（队列视图 / 历史视图 / 失败视图）。
- 在线源配置增加“推荐模板导入”（新手模式）。

## 下载中心体验收口（v2.1 已落地）

- 视图预设快捷入口：顶栏左侧新增 `队列/历史/失败` 统计切换按钮，并支持当前视图高亮。
- 视图内独立记忆：按视图保存关键词、平台筛选、排序设置，切换时自动恢复。
- 重置路径明确：新增 `重置本视图` 按钮，空态也提供同动作入口。
- 统计口径联动：`TransferStatsSummary` 按当前视图输出对应指标（队列/历史/失败）。

### 验收建议

- 在三种视图分别设置不同关键词/平台/排序后切换，确认会恢复上次状态。
- 触发空态后点击“重置本视图筛选”，确认列表和筛选控件同步回默认状态。

## 下载中心交互补强（v2.1 批次二）

- 队列任务菜单按视图显示：仅在`队列`视图展示“任务”批量操作入口。
- 重试语义按视图收口：`失败`视图按钮文案改为“重试失败”，并使用专属提示文案。
- 全局回退入口：更多菜单新增“重置全部视图筛选”，一次清空三视图记忆条件。

## 下载中心交互补强（v2.1 批次三）

- 失败视图专属操作栏：`重试`按钮仅在`失败`视图显示，减少其他视图干扰。
- 空态智能动作：队列空态引导去在线源、历史空态一键切队列、失败空态直接重试。
- 搜索效率增强：新增“清空搜索”按钮，并支持输入框 `Esc` 快速清空当前搜索词。

## 下载中心交互补强（v2.1 批次四）

- 搜索提示按视图动态变化：队列/历史/失败分别给出更精准的关键词提示。
- 筛选空态文案按视图动态变化：避免“同一文案解释所有视图”的理解成本。
- 视图切换自动清空勾选：降低跨视图误操作（误清除/误重试）风险。
- 失败视图重试按钮主色高亮：让核心动作在错误恢复场景中更突出。

## 跨页面体验包（v2.1 批次五）

- 在线源页：新增“清空搜索条件 / 清空链接输入”按钮；搜索与链接输入支持 `Esc` 快速清空。
- 曲库首页：无播放状态下新增“在线源”快捷入口，降低首首歌发现路径成本。
- 播放器栏：全屏入口提示改为动态文案（有内容可全屏 / 暂无可全屏内容）。
- 设置页：播放与音频分组补充“平台能力建议”，帮助用户按系统差异做正确配置。

## 跨页面体验包（v2.1 批次六）

- 在线源页：搜索与链接区补充“清空”动作，支持 `Esc` 快速清空输入，减少反复删改成本。
- 曲库首页：无播放空态增加“下载中心”入口，首屏形成“曲库 / 在线 / 下载”三向分流。
- 播放器栏：队列/歌词入口按播放上下文动态可用，并给出状态化提示文案。
- 设置页：播放与音频分组新增“快速配置”跳转（在线源配置 / 下载策略），降低跨分组操作成本。

## 跨页面一致性包（v2.1 批次七）

- 在线源页：补充统一快捷键提示文案（Enter 执行、Esc 清空）并提供“清空结果”动作。
- 曲库首页：空状态补充快捷键提示，帮助用户快速建立播放操作心智。
- 播放器栏：核心播控与侧边入口提示文案统一为“动作 + 快捷键/状态”格式。
- 设置页：快捷键表补充跨页面高频键位（Enter / Esc）以统一学习入口。

## 跨页面引导包（v2.1 批次八）

- 在线源页：新增“三步上手”引导卡，提供示例填充、前往下载中心、跳转在线源配置三个动作。
- 曲库首页：无播放空态新增“快速设置”入口，降低首用配置跳转成本。
- 设置页（通用）：核心功能区补充跨分组快捷入口（在线源配置/下载策略/播放与音频）。
- 主窗口联动：支持从在线源页一键跳转到设置页并定位到“在线源配置”分组。

## 跨页面效率包（v2.1 批次九）

- 首页空态 CTA 层级统一为“在线源（主）→ 下载中心 → 曲库播放”，并补充统一路径提示。
- 下载中心工具栏新增“去在线源 / 在线源配置”快捷动作，与在线源页的“前往下载中心 / 在线源配置”形成双向闭环。
- 设置页（通用）新增“一键推荐配置”，可快速应用首用推荐参数（并发、默认音质、播放恢复、快捷键）。
- 下载中心状态提示补全：无实时状态时展示统一流程提示，减少页面切换时的决策成本。

## 跨页面反馈包（v2.1 批次十）

- 在线源页与下载中心统一状态反馈为 Ant Alert（成功/失败/信息）三态，降低状态理解成本。
- 在线源与下载中心关键动作补充“不可用原因”提示（如未输入、正在执行、暂无可重试任务）。
- 下载中心空态主动作文案统一为“去在线源”，与首页主路径命名保持一致。
- 设置页底部新增“未保存修改”提示，用户修改后可立即感知需要点击“保存设置”。
- 保持“在线源 <-> 下载中心 <-> 在线源配置”闭环路径，减少跨页迷失。

## 跨页面可观测包（v2.1 批次十一）

- 新增本地轻量可观测服务（仅写入本地设置，不联网），用于记录关键路径使用次数。
- 在线源页接入：搜索尝试/成功、解析尝试/成功、在线源到下载中心跳转、在线源配置跳转。
- 下载中心接入：下载中心到在线源跳转、在线源配置跳转、从下载中心发起播放次数。
- 设置页接入：保存设置次数、推荐配置使用次数；并在“通用”页新增可观测统计卡与一键重置。

## 可观测增强包（v2.1 批次十二）

- 增加按日计数（近 7 天）并在设置页展示 ASCII 趋势小图，便于快速识别使用波峰与空窗期。
- 新增“统计快照导出”能力，支持将 totals + daily 计数导出为本地 JSON（`data/exports`）。
- 增加搜索→下载→播放漏斗转化率提示，帮助从产品视角观察路径流失点。

## 听歌识曲（v2.2 批次一）

- 在线源页新增分段模式：搜索 / 链接解析 / 听歌识曲。
- 听歌识曲支持选择本地音频片段（mp3/wav/flac/m4a/aac/ogg）并执行识别。
- 识别策略支持“外部识曲 API 优先 + 文件名关键词回退”，并自动回填搜索（歌手-歌名优先）。
- 可观测统计新增听歌识曲尝试/成功计数，用于后续评估识别链路质量。
