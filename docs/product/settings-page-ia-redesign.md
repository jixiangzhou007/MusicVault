# 设置页 · 信息架构与 UI 优化（v3 草案）

> 角色视角：产品经理 + UI 设计师  
> 基线代码：`SettingsPageView.axaml`、`SettingsPageViewModel.cs`、`Settings.axaml`  
> 前置：v2 已拆分「在线源 / 下载策略 / 关于与合规」；表单间距与 `settings-field-caption` 已初步统一。

## 1. 设计目标

1. **任务优先**：用户带着「能播放 / 能搜歌 / 能下载 / 能备份 / 能更新」进入设置，而不是按技术模块找字段。  
2. **规则可见**：明确「改完即生效」与「需点保存」的边界，减少误操作与重复点击。  
3. **状态可行动**：每个能力/连接状态附带「原因 + 下一步」，不只显示绿/橙/红标签。  
4. **跨页闭环**：失败或只读项提供一键跳转（已有「前往下载策略」，推广到全站）。  
5. **视觉一套**：全设置页共用字段行、说明文案、操作区、面板三类组件，禁止页内另起炉灶。

## 2. 全局交互模型（P0）

### 2.1 两类内容分区

| 分区 | 内容 | 用户预期 | 当前问题 |
|------|------|----------|----------|
| **配置区** | 文本框、下拉、开关、滑块 | 改后需「保存设置」 | 与操作按钮混排，边界不清 |
| **操作区** | 测试连接、检查更新、导出、备份、恢复 | 点击即执行，有进度/结果 | 与配置区同视觉权重 |

**建议（页内统一结构）：**

```
┌─ 页标题 + 副标题 ─────────────────────────────┐
├─ [可选] 页级 Alert（仅阻断级问题） ─────────────┤
├─ 配置区 A（settings-group）                    │
│    字段行…                                     │
├─ 操作区 B（settings-group，标题「检查与维护」）  │
│    按钮行 + 内联状态 pill                      │
└─ 底栏：保存设置 + 待保存提示 + 操作结果 ────────┘
```

- 配置区标题下增加一行 **settings-field-caption**：`以下选项需点击底部「保存设置」后生效。`（除「通用」「关于」外各页显示一次即可，或放底栏旁）。  
- 操作区按钮不使用与「保存」相同的 primary 样式，保持 `flat-btn`，仅「立即备份 / 重启并安装」等不可逆或高价值动作用 primary。

### 2.2 保存策略（产品决策，二选一）

| 方案 | 优点 | 缺点 | 推荐 |
|------|------|------|------|
| **A. 维持显式保存** | 批量改完再提交；实现已存在 | 用户常忘保存 | 短期保留，加强提示 |
| **B. 自动保存 + 撤销条** | 符合现代设置体验 | 需改 ViewModel 与冲突处理 | 中期目标 |

**阶段 1（A 增强）**：进入有未保存项的二级页时，左侧 Nav 项显示橙点；离开页面前 Confirm（可选）。  
**阶段 2（B）**：配置类字段 debounce 写入；底栏改为「已自动保存 · 撤销」。

### 2.3 左侧导航增强（P2）

```
通用
界面与交互
播放与音频        [·] 均衡器不可用
在线源配置        [!] 未测试 / API 失败
下载策略
备份与恢复
更新与诊断        [1] 有可用更新
关于与合规
```

- 徽标数据来自现有 capability / update / health 绑定，不新增业务逻辑时可先做「更新可用」「在线源 Alert 可见」两类。

## 3. 各二级页线框与优化清单

### 3.1 通用（General）

**用户任务**：了解产品、一键推荐配置、跳转到高频设置。

```
┌─────────────────────────────────────────────┐
│ MusicVault  v1.x.x                          │
│ Tagline + 合规短句（已有）                   │
├─────────────────────────────────────────────┤
│ 核心功能                                     │
│ 推荐配置说明（caption）                      │
│ [一键推荐配置] [在线源] [下载] [播放与音频]   │
├─────────────────────────────────────────────┤
│ 功能卡片 Tab（横向）+ 说明区（已有 antd-card）│
└─────────────────────────────────────────────┘
```

| 优先级 | 优化项 |
|--------|--------|
| P1 | 「一键推荐配置」成功后 Toast + 可选「查看改了什么」摘要（3～5 条） |
| P2 | 功能卡片与下方快捷按钮去重：卡片偏「能力介绍」，按钮偏「去配置」 |
| P2 | 通用页无保存栏 — 保持；避免用户以为要保存 |

### 3.2 界面与交互（UiInteraction）

**用户任务**：改语言、主题、字号、强调色，立刻看到效果。

```
┌─ 界面与交互 ─────────────────────────────────┐
│ 副标题：语言、主题与强调色                    │
├─ 配置区 ─────────────────────────────────────┤
│ 语言      [下拉]                              │
│ 主题      [下拉]                              │
│ 字号      [下拉]                              │
│ 强调色    说明 caption                        │
│           [色块 swatch 网格]                  │
├─ 说明：外观变更立即生效，无需保存。          │  ← 新增（若主题即时）
└─ 底栏：保存 / 不保存 按实际实现二选一写死文案 │
```

| 优先级 | 优化项 |
|--------|--------|
| P0 | **文案与行为一致**：若语言/主题已即时生效，隐藏「保存设置」或仅对「需持久化但未即时」的项显示保存 |
| P1 | 强调色：选中态加 check 图标或外圈，不仅靠 border |
| P1 | 增加「恢复默认外观」次按钮 |
| P2 | 主题下拉旁预览 mini 条（浅色/深色缩略） |

**结构**：本页字段较少，不必 `settings-group`；保持平铺字段行即可。

### 3.3 播放与音频（PlaybackAudio）

**用户任务**：恢复播放习惯、默认播放参数、均衡器、快捷键。

```
┌─ 播放与音频 ─────────────────────────────────┐
│ 副标题：播放、均衡器与快捷键                  │
├─ 分组：平台能力 ─────────────────────────────┤
│ [本地播放 完整] [在线试听 …] [均衡器 …] [API] │
│ （P1）不可用项下增加一行：原因 + [去xxx] 链接   │
├─ 分组：播放默认 ─────────────────────────────┤
│ 启动恢复    说明 caption          [开关]      │
│ 默认音量    [slider]              80%         │
│ 默认循环    [下拉]                            │
│ 默认随机    说明 caption          [开关]      │
│ 默认音质    全部音质  [前往下载策略] 只读      │
├─ 分组：均衡器 ─────────────────────────────┤
│ 均衡器      启用…                 [开关]      │
│ 当前预设    Flat · 摇滚  [打开均衡器]         │
├─ 分组：快捷键 ─────────────────────────────┤
│ 快捷键      启用…                 [开关]      │
│ 快捷键表    [表格]                            │
└─ 底栏：保存设置                              │
```

| 优先级 | 优化项 |
|--------|--------|
| P0 | **默认音质**：保持只读 + 跳转；下载策略改音质后，回到本页应刷新 Summary |
| P1 | 能力标签点击（或右侧 ⓘ）：Popover 显示检测项与修复步骤 |
| P1 | 「快捷键」分组标题与行内标签重复 — 行标签改为「启用」 |
| P2 | 快捷键表：支持「恢复默认」「导出为文本」 |
| P2 | 平台能力窄屏时改为 2×2 网格 |

### 3.4 在线源配置（OnlineSources）

**用户任务**：让搜索/试听/下载链路可用。

**建议 IA 拆为 4 个子分组（仅加 `settings-group-title`，不增二级菜单）：**

```
┌─ 在线源配置 ─────────────────────────────────┐
│ [Alert] 内置 API 待更新（已有）               │
├─ 1. 连接与健康 ─────────────────────────────┤
│ 连接测试   [测试统一 API] [测试网易云] [平台登录] │
│ 统一 API   [url]                              │
│ 识曲 API   [url] + 「查看配置指南」            │
├─ 2. 内置服务 ────────────────────────────────┤
│ 内置 API   [✓] 自动启动…                     │
│ 自动检查   每周…                  [开关]      │
├─ 3. 平台接口 ────────────────────────────────┤
│ 网易云 / 内置网易 / QQ / 夸克 Cookie          │
├─ 4. 采集源 ──────────────────────────────────┤
│ [检测全部] + 列表                             │
└─ 底栏：保存设置                              │
```

| 优先级 | 优化项 |
|--------|--------|
| P0 | **连接测试** 结果内联到按钮右侧（成功绿/失败红） |
| P0 | 识曲 API：可点击「查看配置指南」 |
| P1 | 采集源每行：状态用统一 `ant-tag` |
| P1 | 空 Cookie / 空 URL 时 Nav 徽标「未完成」 |
| P2 | 「平台登录」成功后回写账号状态一行 |
| P2 | QQ、夸克、采集源 URL 放入「更多通道」Expander |

## 4. 组件与视觉规范（UI）

| 元素 | Class |
|------|-------|
| 左标签 | `text-label settings-field-label` |
| 说明 | `settings-field-caption`（禁止内联 Foreground） |
| 只读值 | `settings-field-value-text` |
| 行间距 | `settings-group-body` Spacing=8 |

**面板仅三档**：无面板字段行 / `settings-troubleshoot-panel` / 页顶 Alert。

**按钮**：primary = 保存、备份、重启安装；flat = 测试、导出、跳转。

## 5. 跨页闭环矩阵

| 来源 | 动作 |
|------|------|
| 播放与音频 · 默认音质 | → 下载策略 |
| 播放与音频 · 均衡器不可用 | → 诊断 / 帮助 |
| 播放与音频 · API 异常 | → 在线源配置 |
| 在线源 · 测试失败 | → 故障排查 Tab |
| 备份 · 恢复前 | → 可选导出诊断包 |

## 7. 验收标准

1. 每个二级页 30 秒内能回答「改 X 在哪、要不要保存」。  
2. 「更新与诊断」首屏控件数 ≤ 8（不含 Tab）。  
3. 说明文案统一 `settings-field-caption` 规则。  
4. 跨页跳转 3 条主路径手动通过。  
5. `dotnet build` + `smoke-ui-navigation` 通过。
