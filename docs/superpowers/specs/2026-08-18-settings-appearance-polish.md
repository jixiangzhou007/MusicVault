# 设置 · 外观页产品化精修

日期：2026-08-18  
页序：A 方案第 1 页（外观 → 播放 → 下载 → 数据 → 在线源 → 更新 → 概览）

## 意图

朋友打开「外观」：3 秒内看懂「改显示 → 选强调色 → 必要时恢复默认」；变更立即生效。本页作为后续表单页的结构样板。

## 不做

- 不改强调色盘选项与即时生效逻辑
- 不加实时预览卡
- 不改左栏导航 / 保存模型

## 结构

1. **显示** — 界面语言 / 主题 / 界面字号（`108,12,*`）
2. **强调色** — 组标题 + 色块列表（无外围卡片，左缘对齐控件列）+ **恢复默认**字段行（标签 + flat 按钮，走表单节奏）

页头保留 InstantHint；组内不堆长 Caption。

## 验收

- 三组标题齐全；色块左缘与下拉左缘齐
- Chrome 测试仍绿；发布重启后目视通过
