# UI P0：内容优先沉浸 polish（方案 A）

日期：2026-07-29  
状态：已批准实施按 A」

## 目标

在不改导航 IA / 识曲流程 / 歌单墙的前提下，把「工具台」气质拉向「打开就听」。

## 范围

1. **发现页 chrome 收敛** — 默认单行搜索；更多/非搜索模式展开；传输侧栏默认收起（入队仍可自动展开）。
2. **首页空态** — 氛围视觉 + 一句文案 + 主 CTA「去发现」；次要入口降为文字链接；去掉 Steps 说明书。
3. **全屏播放** — 更大封面、更强氛围底；字号控件弱化。

## 非目标

识曲重写、封面抽色主题、内容主导航、发现信息流。

## 验收

- 打开发现：首屏以结果区为主，搜索带一行。
- 空首页：一眼能点主 CTA，无多按钮工作流感。
- 全屏：封面与歌词为主舞台，顶栏工具不抢戏。
