# 发现浏览中枢：为你精选多列歌表（方案 2）

日期：2026-11-12  
状态：已确认（用户选借鉴 QQ 下区 B → 结构 A 单块 → 落地方案 2）  
对照：现行双栏 `HotRail`/`GuessRail`、`DiscoverHeroPromoLoader` / `DiscoverTrackBatchSlicer`、spec `2026-11-12-discover-dual-rail-browse-design.md`（本轮**取代**双栏区，保留广告 Hero 与「浏览中枢不整页滚动」）  
参考：QQ 音乐「为你推荐」下区多列曲目 + 行悬停操作 + 区侧翻页

## 1. 意图

把广告区下方从「热门 | 猜你喜欢」对称双栏，改成 QQ 式**单块多列「为你精选」**：一屏点歌、悬停可播可藏、右侧悬停翻页换批。保留深色 MusicVault token，不抄 QQ 浅绿品牌色。

## 2. 不做

- 上排 QQ 式精选大卡片墙（用户明确只要下区 B）  
- 新推荐算法、新平台、会员/音质角标体系（Hi-Res 等可后续）  
- 整页或列内滚动条  
- 窄窗改为单列纵向长列表（列数可减到 2，仍多列网格）  
- 改细搜条、搜索结果表、识曲/解析更多区  

## 3. 相对双栏版合同

| `2026-11-12-discover-dual-rail-browse` | 本轮 |
|----------------------------------------|------|
| 左热门 + 右猜你喜欢，各 10 行单列 | **一块「为你精选」多列网格** |
| 栏头各自「换一换」 | **区右侧悬停上一页 / 下一页**（换批） |
| 行点击试听 | 行悬停：**播放叠层** + **收藏**；点击行/播放仍试听 |
| `HotRailTracks` / `GuessRailTracks` | 合并为 `ForYouTracks`（或等价单集合）+ 页偏移 |

广告 Hero（换一换、圆点、试听）**保留**。

## 4. 布局合同

```
┌ 细搜条 ──────────────────────────────────────────┐
├ 广告区 Hero（定高）───────────────────────────────┤
├ 为你精选                              [▶ 可选] ──┤
│  ┌────┐ ┌────┐ ┌────┐     悬停右侧：‹ › 翻页      │
│  │封面│ │封面│ │封面│                            │
│  │歌名│ │歌名│ │歌名│   … 约 10～12 格 / 页       │
│  └────┘ └────┘ └────┘                            │
└──────────────────────────────────────────────────┘
```

- 浏览中枢：`Grid` `Auto,*`（Hero + 精选区），**无**外层 `ScrollViewer`。  
- 列数：宽窗 **3**，中等 **2**（断点用窗口/区宽度，实现可用 Avalonia 宽度阈值或简单阈值阈值）。  
- 每页曲目数：约 **10～12**（例：3×4 或 2×5）；定长一页，网格填满剩余高度，**无列内滚动**。  
- 右侧翻页控件：默认隐藏；指针进入精选区（或右侧热区）时显示；不挡歌名主点击。

## 5. 组件合同

### 5.1 区头

- 标题：`为你精选`（l10n）。  
- 副文案（可选）：短说明，如「根据口味挑选」。  
- 整区播放（可选 P2）：有现成「批量预览/入队」再接；本轮可不做，留位即可。

### 5.2 曲目格

- 内容：封面缩略图 + 歌名 + 歌手。  
- 悬停行：  
  - 封面中心播放（走现有 `PreviewCommand` / 底栏试听）；  
  - **收藏**心形（现有在线收藏 `IsOnlineFavorite` / toggle）；  
  - 不要「更多 ⋯」菜单（YAGNI，本轮不做）。  
- 未悬停：不显示播放叠层与收藏（或收藏仅在已收藏时弱显示——实现选一，优先悬停才出操作，已收藏可用实心弱显）。

### 5.3 翻页

- 上一页 / 下一页：换下一批同页容量曲目；`exclude` 当前页 id；池耗尽绕回（复用 `DiscoverTrackBatchSlicer`）。  
- 加载中禁用翻页。  
- 与 Hero「换一换」独立 offset。

## 6. 数据职责

| 区域 | 源 |
|------|-----|
| 广告区 | 现有 `DiscoverHeroPromoSource` |
| 为你精选 | **猜你喜欢池为主**；不足用热门池补齐；可选弱提示「已混入热门」 |

- 尽量 exclude 当前 Hero 批 id，降低与广告区撞歌。  
- 加载失败：区短文案 + 重试；不整页变设置。

## 7. 状态与可见性

- `ShowBrowseHub` / 搜索会话规则不变。  
- 清除搜索后恢复 Hero + 为你精选。

## 8. 验收

- [ ] 无搜索时：无左右双栏标题「热门歌曲 / 猜你喜欢」并排单列。  
- [ ] 有「为你精选」多列网格；宽≈3 列、缩窄≈2 列。  
- [ ] 浏览中枢无页面滚动、列内无滚动条。  
- [ ] 悬停行可见播放与收藏；收藏切真实状态。  
- [ ] 区右侧悬停出现翻页；可换出与当前页不同的一批（池足够时）。  
- [ ] 广告 Hero 行为不回退。  
- [ ] 搜索会话仍隐藏浏览中枢。  
- [ ] `publish-with-api.ps1 -Restart` 可点验。

## 9. 文案 key（建议）

- `Discover.ForYou.Title` = 为你精选  
- `Discover.ForYou.Subtitle` = 根据口味挑选（可选）  
- `Discover.ForYou.PrevPage` / `NextPage` = 上一页 / 下一页  
- `Discover.ForYou.MixedHotHint` = 已混入热门（可选）  
- `Discover.ForYou.Empty` / `Retry` = 暂无曲目 / 重试  

## 10. 风险

- 矮窗 3×4 可能偏紧 → 优先减行高/封面，仍不滚动；再不行本页改为 2×5。  
- Avalonia 悬停翻页按钮抢焦点 → 热区与 `IsHitTestVisible` 需实机调。  
- 双栏 VM/XAML 将删除或停用；注意不要留下死绑定。
