# 整理工具 · 刮削优先 + 底栏操作台

**日期：** 2026-11-12  
**状态：** 已落地  
**依据：** 用户确认方向 A（刮削优先）+ 布局 A（底栏操作台）

---

## 1. 目标

整理工具页以**歌曲元数据刮削**为主路径，做到更清晰、更好用：

1. 一眼知道要先载入队列，再刮削。  
2. 队列始终占主视觉区；刮削操作集中在底栏，不与列表抢注意力。  
3. 重命名文件、去重不挤占主带，收到次要入口。

非目标（本期不做）：四步向导/步骤条重做、常驻左右分栏核对台、自动载入整库、多队列方案。

## 3. 信息架构

```
整理工具（单页）
├── 主路径：载入 → 勾选字段 → 开始刮削 → 结果反馈
└── 更多（次要）：重命名文件、去重（及日后整理预览等）
```

- **默认作用范围：** 仅已选；无选中时提示先勾选，或提供「刮削整清单」显式选项（沿用现有范围语义，控件放底栏次要位）。  
- **从曲库入队：** 继续支持合并进整理队列；进入本页后直接可见队列 + 底栏。

## 4. 布局

```
┌─────────────────────────────────────────────────────────────┐
│ 音乐库 ▼  [载入]     共 N 首 · 已选 M     [更多 ▾]            │  ← 顶行
├─────────────────────────────────────────────────────────────┤
│ 队列列表（全宽，可滚动）                                      │
│ # 选  歌曲  艺术家  专辑  …  标签  封面  歌词  操作            │
│ …                                                           │
├─────────────────────────────────────────────────────────────┤
│ 字段 chips · 数据源 · 套餐 · 范围        [开始刮削]           │  ← 底栏（有队列时）
└─────────────────────────────────────────────────────────────┘
```

### 4.1 顶行

- 音乐库选择 + **载入**（不自动随切库载入）。  
- 摘要：`共 N · 已选 M`（可含队列来源一句，若已有文案则复用）。  
- **更多**：MenuFlyout — 至少「重命名文件」「去重」；无队列时对应项禁用并 ToolTip 说明需先载入。

### 4.2 中部队列

- 虚拟列表与现有列（含标签/封面/歌词状态、行内删除）保留。  
- 全选 / 清空选择 / 清空队列：靠列表上方工具行或顶行旁，**不**回到臃肿双工具带。  
- 刮削中：行状态更新；可用轻量顶/底进度，避免与全屏进度模态重复堆叠（见 §5）。

### 4.3 底栏（`HasWorkingSet` 时显示）

- **字段 chips：** 标题、艺术家、专辑、年份、封面、歌词等（与现有 `BatchScrape` 字段对齐；高级字段若保留，进「更多字段」展开，默认不铺满一行）。  
- 数据源、刮削套餐：紧凑下拉。  
- 作用范围：仅已选 / 整清单。  
- 主按钮：**开始刮削**（`primary`）；取消仅在运行中显示。  
- 空队列：底栏隐藏；空态引导载入或去曲库加入。

## 5. 刮削流程（行为）

保持现有服务链：`StartBatchScrape` → 确认 → `BatchOnlineScrapeService.ScrapeOneAsync` → 结果。

体验约束：

1. **确认弹层**可留（破坏性/写盘前）。  
2. **进度：** 优先一种主反馈（弹层进度 **或** 底栏+行内进度），避免页内条 + 全屏模态 + Toast 三重同义提示；实现时收敛为「确认 → 进度（单一）→ 结果摘要」。  
3. 取消：运行中可取消；取消后队列状态一致、可重试。  
4. 失败行：列表状态可见；结果摘要给出成功/跳过/失败计数。

查找替换、路径模板整理预览：本期可不挂主 UI；若代码仍在 VM，允许保留命令但不上主路径（或仅「更多」占位，不强制做完）。

## 6. 视觉与易用

- 底栏固定于页面内容区底部（不挡壳层播放栏）；高度紧凑，字段过多时 chips 可换行或「常用 / 扩展」两档。  
- 主按钮仅「开始刮削」与「载入」使用强调色；「更多」为 flat。  
- 空态需有明确 CTA（载入或跳转曲库），修正当前 `ShowWorkSetEmptyAction => false` 的弱引导。

---

## 7. 验收标准

1. 打开整理工具：无双行臃肿刮削/重命名/去重顶栏；顶行仅载入相关 + 更多。  
2. 载入或从曲库入队后：出现底栏；字段 / 源 / 套餐 / 范围 / 开始刮削可用。  
3. 主路径可完成一次批量刮削并看到结果；队列列状态更新。  
4. 重命名、去重仅从「更多」进入，行为不弱于改版前（能完成同一任务）。  
5. 空态有可点击引导；无队列时不能误触开始刮削。  
6. `PRODUCT_DESIGN` 能力矩阵中整理工具相关表述与本 spec 一致（实现后改文档）。
