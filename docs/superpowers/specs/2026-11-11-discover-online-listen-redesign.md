# 发现页重设计：在线听主场（推荐 | 搜索对等）

日期：2026-11-11  
状态：已确认（用户 2026-11-11）  
对照：`SearchPageView` / `SearchPageViewModel`、`DiscoverBrowseHubState`、双核 PRODUCT_DESIGN（发现 = 核心 B）、竞品（网易云 / QQ PC：内容先行、搜索为顶栏工具）

## 1. 意图

把发现从「多源搜索工作台」改成**在线听的核心页**，与本地播放对等。

结构合同：**顶部分段「推荐 | 搜索」对等、互斥、整页切换**（路径 A）。  
推荐态像「今天听什么」；搜索态像「找了就听」。同一底栏出声。

已确认：首屏主职 = 两者对等切换（非纯逛、非纯搜）；落地 = 顶部分段 + 两态整页。

## 2. 不做

- 新推荐算法、新平台、新远程协议  
- 识曲采集交互重写（麦克风/选文件流程冻结）  
- 会员墙、社交、皮肤、AI 伴听  
- 本轮不强制恢复右侧传输通栏（点名再开）  
- 不改全局顶栏 Tab 数量  

## 3. 信息架构

| 区域 | 行为 |
|------|------|
| 页顶分段 | **推荐 \| 搜索**；会话内可记住；**默认进入推荐** |
| 推荐态 | 主 CTA + 榜单轨 + 歌单墙；无大搜框、无模式表单、无登录胶囊矩阵 |
| 搜索态 | 吸顶搜框（歌名 + 平台 + 搜索 + 清除）+ 结果表；识曲 / 粘贴链接在「更多」内默认收起 |
| 失败 / 健康 | **统一源失败条以搜索态为主**；推荐态仅轻量健康点或不打断逛 |
| 播放 | 封面/行/识曲播放条 → 同一 `PlayerBar` 在线试听 |

推荐态点主 CTA「搜索」→ 切到搜索态并聚焦输入框。  
搜索有进行中会话时切到推荐再切回：保留查询与结果（不清空）。

## 4. 推荐态合同

1. 顶栏：分段 + 可选极轻 API 健康点（绿/灰），不铺长失败条。  
2. 一块主 CTA：续听 → 否则逛精选焦点（沿用 `DiscoverPrimaryCta` 优先级；「聚焦搜索」类动作改为切分段）。  
3. 榜单横滑 + 歌单封面墙（现有数据源）。  
4. 点榜单/歌单 → 现有打开逻辑；点曲 → 底栏试听。  
5. 区块空/失败：短文案 + 重试，不整页变设置。  

## 5. 搜索态合同

1. 吸顶：歌名、平台、搜索、清除。  
2. 默认不展开：艺人附加行、识曲、粘贴链接；「更多」一次展开。  
3. 有结果：结果表为主舞台；统一源失败条可在结果上方。  
4. 识曲成功：留在搜索态；保留播放 / 下一首条（已落地能力）。  
5. 空搜：短引导「输入歌名」；不做新热搜引擎（静态/现有即可）。  

## 6. 相对旧合同

| 旧（`2026-07-31-discover-browse-hub-design` 等） | 本轮 |
|------------------------------------------------|------|
| 搜前 = 浏览态（Hero 大搜 + 精选）；搜后 = 结果 | **显式分段**；推荐态 **无** Hero 大搜 |
| 清空搜索 → 回精选 | 清空仍回推荐内容；**切分段**不自动清查询 |
| 主 CTA「去搜索」→ 聚焦框 | 改为 **切到搜索态并聚焦** |
| 失败条可与浏览叠层 | **以搜索态为主**展示统一源失败条 |

双核对等切片 2（主 CTA + 失败条）能力保留，改触发与壳层，不删功能。

## 7. 迁移与实现边界

- 优先重组 `SearchPageView` 可见性与分段状态；复用 Browse Hub / 搜索 / 识曲逻辑。  
- `DiscoverBrowseHubState` / Primary CTA / SourceFailureBanner：按两态调整触发条件，避免推荐态叠工具壳。  
- 传输速览列保持现状（宽 0）除非另开任务。  
- 用户确认本 spec 后：更新 `PRODUCT_DESIGN.md` §7.4 表述；再写实现计划。  

## 8. 验收

1. 冷启动进发现：首屏是可听内容（推荐态），不像探针/设置台。  
2. 切搜索：一眼能搜、结果能出声。  
3. 识曲/粘贴不在推荐态默认露出。  
4. 顶栏导航项数不变；底栏同一套。  
5. `publish-with-api.ps1 -Restart` 后肉眼过两态。  

## 9. 风险

| 风险 | 缓解 |
|------|------|
| 分段与旧 Hero/Compact 双壳并存混乱 | 推荐态去掉 Hero 大搜；搜索态只留一套吸顶壳 |
| 登录胶囊消失后权限不清 | 搜索失败条 + 设置入口；推荐态不展开矩阵 |
| 用户找识曲 | 「更多」内保留；可后续加搜索态次入口，不回推荐首屏 |
