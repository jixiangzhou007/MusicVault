# 设置 · 概览页「关于书」重设计

日期：2026-11-13

## 意图

概览是听歌软件的「关于 + 轻量快捷入口」，不是运营仪表盘。

## 已定方向

- 第一职责：关于（身份 / 说明 / 开源）
- 曲库 KPI：迁到「数据」分区；概览不再展示
- 快捷入口：保留轻量跳转；「一键推荐配置」仅在无库来源且无曲目时作主 CTA
- 功能 Tab 轮播：删除；能力说明并入关于正文（若干短段）
- 布局：单栏「关于书」——身份 → 关于 → 快捷入口

## 结构

1. **身份**：应用名 / 版本 / 标语 / 合规短句  
2. **关于（始终展开）**：产品 lead + 一句能力总述 + 许可与开源芯片（无 disclosure 外壳；不铺六段功能说明书）  
3. **快捷入口**：外观 / 播放 / 下载 / 在线源；空库引导与推荐配置按需出现  

## 数据页

页顶增加「曲库一览」KPI（原概览五格）与刷新 / 管理库来源 header actions。

## 不做

双栏侧栏入口、品牌 Hero 大卡、恢复功能 Tab。
