# 设置 · 概览页产品化精修

日期：2026-08-20  
页序：A 方案第 7 页（收官）

## 意图

概览像听歌软件的「关于 + 快捷入口」，不像运营仪表盘。

## 结构

1. **身份**：应用名 / 版本 / 标语 / 合规短句（扁平，无卡片壳）
2. **曲库一览**：五格 KPI，弱背景（降 AccentSoft 块感）
3. **快捷入口**：空库引导、推荐配置、跳转外观/播放/下载/在线源
4. **功能介绍**：保留 Tab 卡片（能力扫读）
5. **关于与开源**：disclosure（产品说明、版权、开源芯片、设计预览）

## 不做

左栏、保存模型、拆 VM、删 KPI/功能 Tab。
