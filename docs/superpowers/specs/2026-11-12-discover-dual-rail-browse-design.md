# 发现浏览中枢：广告区 + 双栏定长歌曲（方案 2）

日期：2026-11-12  
状态：已确认（用户选方案 2；列内策略选 B：定长 10 首 + 换一换；页面不滚动）  
对照：现行 `SearchPageView` 浏览中枢、`DiscoverHeroPromoLoader`、spec `2026-11-11-discover-qq-listen-shell-design.md`（乐馆壳保留；本轮改推荐流下半）

## 1. 意图

把发现「无搜索会话」态收成**一屏听歌台**：上方广告轮播试听，下方左右两列歌曲列表。去掉封面墙式「推荐歌单」与横滑「热门榜单」轨，减少逛封面、强化点歌。

## 2. 不做

- 新推荐算法、新平台 API、会员墙  
- 把双栏改成可整页滚动或列内第二滚动条  
- 窄窗改为上下堆叠双栏  
- 改细搜条、搜索结果表、识曲/解析「更多」区  
- 改设置里 Hero 数据源枚举语义以外的设置页大改（可沿用现有「广告区数据源」）

## 3. 相对现行浏览中枢

| 现行 | 本轮 |
|------|------|
| 广告 Hero + 横滑热门榜单封面 + 推荐歌单封面 | **广告 Hero + 左热门歌曲 + 右猜你喜欢** |
| `BrowseHubScroll` 整页可滚 | **浏览中枢无页面滚动**；剩余高度由双栏吃满 |
| 榜单/歌单卡片进歌单页 | 双栏直接出**曲目行** → 同一底栏试听 |
| Hero「换一换」换 10 首轮播 | 保留；双栏各自「换一换」换本栏下一批 10 首 |

## 4. 布局合同

```
┌ 细搜条（常驻） ─────────────────────────────────┐
├ 广告区 Hero（定高 DiscoverHeroHeight）──────────┤
│  左上「换一换」 · 右文案/试听 · 底圆点           │
├────────────────────┬────────────────────────────┤
│ 热门歌曲    换一换 │ 猜你喜欢            换一换 │
│ 行 × 10（定长）    │ 行 × 10（定长）             │
└────────────────────┴────────────────────────────┘
```

- 浏览中枢容器：`Grid`（或等价）`RowDefinitions=Auto,*`：Hero `Auto`，双栏 `*` 填满搜条与底栏之间剩余高度。  
- **禁止**浏览中枢外层 `ScrollViewer` 产生页面滚动。  
- 双栏等宽（`*` / `*`），中间细缝用既有 spacing token。  
- 每栏：栏头（标题 + 换一换）+ **固定 10 行**；行高与字号在剩余高度内自适应或采用固定行高并允许底边裁切，**不得**再套列内滚动条。  
- MinWidth 下仍保持双栏；只允许压缩行内边距，不改为单列堆叠。

## 5. 组件合同

### 5.1 广告区（保留并沿用）

- 全幅氛围取色（无左侧独立方封）。  
- 左上「换一换」、右文案 + 试听 / 主 CTA、底圆点手动切换。  
- 数据：`DiscoverHeroPromoSource`（新歌榜 / 猜你喜欢轮播），`DiscoverHeroPromoLoader` 池切片，一批 10 首。

### 5.2 曲目行（双栏共用）

- 内容：封面缩略图 + 歌名 + 歌手（可次要色）。  
- 交互：点击行或行内试听 → 现有在线试听 / `PlayerBar`；权限与登录失败沿用发现页既有提示，不新开失败态机。  
- 空/加载：栏内骨架或短文案 + 重试；不整页变设置台。

### 5.3 栏头「换一换」

- 排除当前栏已展示的 id，从本栏曲目池取下一批 10 首；池耗尽则绕回。  
- 加载中禁用按钮（与 Hero 换一批一致）。

## 6. 数据职责（防撞车）

| 区域 | 源 | 说明 |
|------|-----|------|
| 广告区 | 设置 `DiscoverHeroPromoSourceIndex` | 轮播试听；与双栏独立换批 |
| 左 · 热门歌曲 | 热歌 / 飙升等榜单曲目池 | 优先具名榜；失败则新歌池另一段 |
| 右 · 猜你喜欢 | 个性化推荐 / 每日推荐池 | 失败降级到热门池**不同 offset** 的切片，并弱提示「暂用热门」 |

- 实现可复用/扩展 `DiscoverHeroPromoLoader` 的池切片与 exclude 逻辑，或抽共用 `DiscoverTrackPoolLoader`；避免三处各写一套网易云请求。  
- 默认每栏 `Take = 10`，与 Hero 一致。

## 7. 状态与可见性

- `ShowBrowseHub` / 搜索会话规则**不变**：有活跃搜索会话时隐藏浏览中枢，显示结果表。  
- 清除条件 / 再点「发现」仍回到本双栏浏览页。

## 8. 验收

- [ ] 无搜索会话：无推荐歌单区、无横滑榜单封面轨。  
- [ ] 浏览中枢整页不出现垂直滚动条；双栏列内也无滚动条。  
- [ ] 左栏标题「热门歌曲」、右栏「猜你喜欢」；各恰好展示至多 10 行。  
- [ ] 各「换一换」能换出与当前批不同的曲目（池足够时）。  
- [ ] 点击行可试听，进同一底栏。  
- [ ] 提交搜索后双栏消失；清除后双栏恢复。  
- [ ] 发布 `publish-with-api.ps1 -Restart` 后可人工点验。

## 9. 文案 key（建议）

- `Discover.Rail.HotTitle` = 热门歌曲  
- `Discover.Rail.GuessTitle` = 猜你喜欢  
- `Discover.Rail.Refresh` = 换一换（可与 Hero 共用或分 key）  
- `Discover.Rail.GuessFallbackHint` = 暂用热门（弱提示，可选）

## 10. 风险

- 矮窗口：10 行可能被裁切 → 接受定长优先于完整可见；若实机过挤，实现阶段可将行高 token 下调，仍不引入滚动。  
- 猜你喜欢与 Hero 同选「猜你喜欢」源时内容可能相近 → 用不同 offset / exclude 当前 Hero 批降低重合。
