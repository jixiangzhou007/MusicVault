# 首页黑胶唱臂换写实素材（设计）

日期：2026-11-10  
状态：已实现（改回网易云式俯视平面臂；弃用立体写实 PNG）  
对照：`VinylRecordCoverView`、`Assets/vinyl-tonearm.png` / `.svg`、首页封面控件

## 1. 意图

首页（及共用 `VinylRecordCoverView` 之处）的唱臂从「示意图 SVG→PNG」换成**银白哑光、透明底写实唱臂**，播放/暂停仍绕螺丝枢轴摆动，观感更接近真唱机。

已确认：方向 **写实透明素材**；质感 **银白哑光**；素材 **先网上可商用图，不行再 AI**；实现路径 **A · 整图替换 + 重校枢轴**。

## 2. 不做

- 不重做唱机底盘、皮纹台面、整机机箱  
- 不加唱臂皮肤切换 / 多套主题资源  
- 不拆「螺丝控件 + 臂身贴图」双层方案（路径 B）  
- 不改黑胶纹槽、封面旋转、播放状态机语义（仅校准摆臂角度与原点）  
- 不为仅换图去改全局设计系统  

## 3. 资产合同

| 项 | 要求 |
|----|------|
| 格式 | PNG，真透明底（无灰底、无伪透明） |
| 风格 | 银白哑光金属；柔和高光；避免高光铬条抢封面 |
| 构图 | 左上（或明确一侧）螺丝枢轴 + 斜向臂管 + 唱头/唱针；唱头朝向盘心一侧 |
| 尺寸 | 建议 ≥2× 显示尺寸（当前显示约 92×138） |
| 枢轴 | 图内螺丝清晰，便于量归一化渲染原点 |
| 授权 | 可商用素材或自有 AI；在资源旁留一行来源备注（如 SVG 注释或 `Assets` 旁短说明） |

流程：搜索候选 → 验收上表 → 不合格则 AI 按同表生成 → 再验收。

## 4. 代码落点（路径 A）

1. 替换 `src/MusicVault.App/Assets/vinyl-tonearm.png`（可选同步重画/归档 `vinyl-tonearm.svg`）。  
2. 按新图螺丝中心设置 `VinylRecordCoverView` 中 `TonearmPivotX` / `TonearmPivotY`（相对控件宽高的比例）。  
3. 调整 `TonearmHost` 的 `Canvas.Left/Top`（及必要时宽高），使：  
   - 暂停态：针尖在盘外/槽边附近（基准约 -30°，可 ±5°）  
   - 播放态：针尖落入纹槽区（基准约 0°，可 ±5°）  
4. 不改 `DiscHost` 旋转与封面绑定。  

## 5. 验收

1. 透明边缘干净，银白哑光观感成立。  
2. 播放↔暂停摆臂动画：不穿过封面中心圆、不飞出 Canvas。  
3. 凡使用 `VinylRecordCoverView` 的页面一致换新臂。  
4. `publish-with-api.ps1 -Restart` 后肉眼确认。  

素材不满意时：同一合同下只换 PNG 并重校枢轴，不改控件结构。

## 6. 风险

| 风险 | 缓解 |
|------|------|
| 免费站授权不清 | 优先明确可商用；否则 AI 自有 |
| 新图比例导致悬空/穿盘 | 路径 A 强制重校枢轴与停放角 |
| AI 白边 | 验收拒收；重生成或抠图后再入库 |
