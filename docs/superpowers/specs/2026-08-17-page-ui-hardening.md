| 项 | 内容 |
|----|------|
| 日期 | 2026-08-17（按用户反馈重写：整体性、统一、好用、主流审美、Win+Mac） |
| 对照 | PRODUCT_DESIGN §6 壳层；DESIGN_SYSTEM Token；主流桌面播放器（Apple Music / Spotify 桌面，不是后台控制台） |

## 1. 设计意图

MusicVault 是**一个桌面音乐播放器**，不是 Ant Design 后台。朋友打开后应感到：顶栏选去哪、中间浏览或搜索、底栏一直在播。Windows 和 Mac 是**同一套产品 UI**，只在**窗口铬（窗框、交通灯、标题栏合并）**上跟随系统。

四条合格线：

1. **整体性：** 先定 4 种页模板，各页套模板，禁止再发明第五种页头。
2. **统一：** 标题一律左对齐；工具栏同一套主按钮 + 溢出菜单；间距走 Token。
3. **好用：** 朋友要做的事（听、搜、导入、载入）一眼能点；合并/刮削字段/批量进「更多」或载入之后。
4. **平台：** Win 继续自绘标题栏 + 右上角窗控；Mac 合并系统标题栏，交通灯在左，不画 Win 那套红黄绿仿品，也不在交通灯下面再放 Logo。

参照（气质，不是抄皮肤）：

| | 学什么 | 不学什么 |
|--|--------|----------|
| Apple Music / Spotify 桌面 | 底栏常驻、封面带列表、页头短、主操作极少 | 流媒体商店、社交 |
| 网易云 / QQ 桌面 | 顶部分区、搜索即听 | 下载商城、会员墙 |
| Fluent / Win11 | 右上窗控、略密、Segoe Fluent 图标 | Mica 整窗重做 |
| macOS HIG | 左上交通灯、标题栏与内容合一、略松 | SF Symbols 整套替换（本波不做） |

## 2. 共享 vs 平台（必须分清）

**共享（两平台同一套）：** 顶栏五个文字 Tab、曲库二级条、底栏播放器、Token、按钮层级、四种页模板、Fluent 图标字体（本波不换）。

**仅平台窗框不同：**

| | Windows（现行，保持） | macOS（本专项要补） |
|--|----------------------|---------------------|
| 系统装饰 | `SystemDecorations.None`，自绘最小化/最大化/关闭在**右侧** | 系统交通灯在**左侧**，禁止再画一套窗控 |
| 标题栏 | 导航条即标题栏（已合并） | 现在是系统标题栏 + 应用顶栏**两截**；改为 `ExtendClientAreaToDecorationsHint`，导航条吃进标题栏 |
| 左内边距 | Logo 贴左即可 | 顶栏左侧为交通灯留 `TitleBarLeadingInset`（约 78px，Token） |
| 窗外框 | `WindowShell` 6px 圆角 + 1px 描边 | 取消假描边，圆角跟系统；不要 Win 风格描边框 |
| 图标 | Fluent 原生感好 | Fluent 略「Win」，本波接受；不换字体 |

能力差异（下载、桌面歌词）继续按 PRODUCT 门禁，**不要做成另一套 UI 皮肤**。

## 3. 四种页模板（只准这四种）

对照物：歌曲页（T1）已经最接近主流播放器。

| 模板 | 结构 | 用于 | 页头规则 |
|------|------|------|----------|
| **T1 左栏列表** | 左 260 源列表 + 右曲目表 | 歌曲、库来源 | 无大段 Hero；左栏标题 + 图标溢出菜单（歌曲页已是） |
| **T2 实体浏览** | 左对齐标题 + 一行筛选 + 列表 | 艺术家、专辑、歌单浏览 | 标题左；说明最多一行；工具栏 1 primary + 可选 1 个可见次要 + `···` |
| **T3 搜索听** | 居中/吸顶搜索 + 结果表 | 发现 | 打开全宽；传输栏入队再展开；识曲仍在「更多」 |
| **T4 任务/工具** | 短标题 + 一步主操作 + 表格 | 下载任务、整理 | 未就绪时只露「先做的那一步」（载入 / 看队列） |

设置维持现有左 7 段（冻结），但段内按钮仍服从「同时可见最多一个 primary」。

**工具栏合同（所有模板）：**

- 同时可见最多 **一个** `primary`（听、搜、导入、载入、保存）。
- 朋友高频次要动作可留一个 `flat-btn`（如新建歌单）。
- 其余进 `MenuFlyout` + `app-compact-menu-item`（抄歌曲页左栏 `+` / 更多，不要新控件）。
- 删除不进工具栏实心红钮；放溢出菜单即可。
- `page-title` 禁止 `HorizontalAlignment="Right"`（那是表单标签对齐，不是播放器）。

## 4. 各页套模板后的样子

| 页 | 模板 | 做完后朋友怎么用 |
|----|------|------------------|
| 歌曲 | T1 | 保持；溢出菜单已有 |
| 艺术家 / 专辑 | T2 | 标题改左；说明缩短且不提下载；搜索仍是该行 primary |
| 歌单浏览 | T2 | 导入 primary；新建可见 flat；合并进 `···` |
| 歌单详情 | T2 | 播放/在线听 primary；编辑删除导出加载更多进 `···` |
| 发现 | T3 | 默认全宽；入队展开传输栏（已有开关，修首帧 280） |
| 整理 | T4 | 未载入只见选库+载入；刮削带载入后出现 |
| 下载任务 | T4 | 短副标题；批量暂停/取消已在更多菜单则保持 |
| 首页 / 底栏 / 设置壳 | — | 本波不重做；底栏已是主流结构 |

## 5. 不做

- 换主题、新 Accent、新图标字体、仿 Spotify 绿 / 仿 Apple 红
- 左右两套完全不同的页面布局
- 识曲重写、设置改成 4 项、拆巨型 VM
- 为「像 Mac」而改掉 Win 右上窗控
- 在 Mac 上画假交通灯

## 6. 验证

- Win：发布重启后五页套模板肉眼一致；设计系统审计 0 View hex
- Headless（Win）：发现默认收起；歌单浏览可见 primary 仅为导入；艺术家标题非 Right
- Mac：代码层交通灯 inset + 无右侧假窗控；实机列入 `docs/GITHUB_RELEASE.md` 清单（本机若无 Mac 不挡 Win 交付）
