## 1. 软件定位

MusicVault 是**个人本地音乐库管理工具**：索引用户自有或合法获得的音频文件，并提供整理、播放、元数据编辑等功能。

- **不提供**任何受版权保护的音乐作品本身。
- **不运营**音乐流媒体服务。
- **默认不向开发者服务器上传**曲库、播放记录或账号密码（除非用户自行配置远程 API，数据发往该第三方）。

3. 不得将本软件用于侵犯他人知识产权、传播盗版、商业性再分发受保护作品等用途。

**开发者不对用户行为导致的法律后果承担责任。**

## 3. 非官方音乐平台接口

MusicVault 可通过用户配置或可选捆绑的本地服务，访问网易云、QQ 音乐、酷狗等平台相关的**非官方**接口（如 NeteaseCloudMusicApi、go-music-api）。

- 这些接口**未经**平台官方授权或认可。
- 接口可用性、稳定性、返回数据准确性**无保证**。
- 使用可能违反部分平台用户协议；**风险由用户自行承担**。
- 生产环境建议**自建 API** 于本机或可信网络，勿依赖公共演示节点。

## 6. 隐私与本地数据

默认情况下，用户数据保存在本机，例如：

| 路径（Windows 示例） | 内容 |
|----------------------|------|
| `%LOCALAPPDATA%\MusicVault\musicvault.db` | 曲库索引、播放列表、艺术家缓存等 |
| `%LOCALAPPDATA%\MusicVault\Downloads\` | 下载文件（可配置） |
| `%LOCALAPPDATA%\MusicVault\music-api-cookies.json` | 平台 Cookie（若使用平台登录） |
| `%LOCALAPPDATA%\MusicVault\settings.json` | 应用设置 |

- 本开源版本**不包含**内置遥测、广告或用户行为上报模块。
- Cookie 与 API 凭据以**本地明文或系统保护**方式存储；请在共享计算机上谨慎使用。
